# scrib7

Projet similaire à scribbl.io, un jeu multijoueur en ligne où les joueurs dessinent et devinent des mots.
Le projet est séparé en deux parties : le frontend et le backend. Le frontend est développé en utilisant Vue.js et le backend est développé en utilisant Node.js avec Express.

Nous utilisons websocket pour la communication en temps réel avec le package `ws`.

Nous utilisons également `pnpm` pour la gestion des dépendances.

## Installation

1. Clonez le dépôt
2. Installez les dépendances avec `pnpm install`
3. Lancez le projet avec `pnpm run dev`
